# Known Limitations

## Geolocation
- Proximity alert depends on browser GPS accuracy
- Desktop testing requires simulated location
- Some devices may have inconsistent location updates

## Mobile Behaviour
- Layout varies slightly across different screen sizes
- Sidebar width may vary depending on device resolution

## Performance
- Cesium 3D dashboard depends on internet speed and browser capability
- Large datasets may reduce rendering performance

## API
- Limited input validation on some endpoints
- Error messages could be further standardised

## User Experience
- Alerts used instead of modal notifications in some cases
- No authentication (user identified via database session only)

---

## Summary
These limitations do not affect core functionality but highlight areas for future improvement.
